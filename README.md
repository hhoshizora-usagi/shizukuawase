# しずくあわせ 🍉

液体版スイカゲーム（ブラウザで遊べる試作版）。

ぷるぷるの液体を落として、同じ液体どうしをくっつけると、ひとつ大きな液体に進化します。最後の液体「スイカジュース」を目指そう！

## 遊び方

- ボトルの上でねらって、クリック（スマホはタップ）で液体を落とす
- 同じ液体どうしがふれると、ぷるんと合体して次の液体へ
- ボトルをかたむけて（A / D キー、または画面下のボタン）液体をゆらして寄せられる
- 赤い点線より上に2秒以上あふれたらゲームオーバー

## 液体の進化（全11段階）

しずく → ソーダ → メロンソーダ → レモネード → オレンジ → いちごミルク → グレープ → はちみつ → ブルーハワイ → まっちゃラテ → スイカジュース

## キーボード操作

| キー | 動作 |
| --- | --- |
| ← → | ねらいを動かす |
| Space | 落とす |
| A / D | ボトルをかたむける |
| Esc | 一時停止 |
| R | リスタート |

`index.html` 1ファイルだけで動きます。ダウンロードしてブラウザで開いても遊べます。
