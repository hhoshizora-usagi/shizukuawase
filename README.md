# しずくあわせ 💧

液体版スイカゲーム（ブラウザで遊べる試作版）。

水銀みたいにころころ転がる水滴を落として、同じ色どうしをくっつけると、ひとつ大きな水滴に進化します。最後の「スイカジュース」を目指そう！

## 遊び方

- ボトルの上でねらって、クリック（スマホはタップ）で水滴を落とす
- 落ちているあいだはしずくの形、着地すると水銀みたいにまん丸の玉に
- 同じ色が近づくと、きゅっと引き寄せあって合体
- ボトルをかたむけると（A / D キー、または画面下のボタン）水滴がつるっと転がる
- 赤い点線より上に2秒以上あふれたらゲームオーバー

## 水滴の進化（全11段階）

しずく → ソーダ → メロンソーダ → レモネード → オレンジ → いちごミルク → グレープ → はちみつ → ブルーハワイ → まっちゃラテ → スイカジュース

## キーボード操作

| キー | 動作 |
| --- | --- |
| ← → | ねらいを動かす |
| Space | 落とす |
| A / D | ボトルをかたむける |
| Esc | 一時停止 |
| R | リスタート |

`index.html` 1ファイルだけで動きます。ダウンロードしてブラウザで開いても遊べます。
